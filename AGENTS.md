# Beyond Green

A post-test investigation loop: after an E2E test passes, agents gather and
challenge evidence to decide whether the system actually behaved correctly.
[README](README.md) carries every command and measured result. The
[MVP plan](Beyond%20Green%20%E2%80%94%20Hackathon%20MVP%20Plan.md) carries the
product definition and build order.

## Working rules

- Commit at each logical milestone. Write a clean, imperative subject line and
  end the message there, with no attribution or co-author trailers.
- Use the Matt Pocock skills: `tdd` for new behaviour, `codebase-design` for
  module boundaries, `diagnosing-bugs` for failures, `research` for external
  sources, `writing-for-agents` for documents agents read.
- Remaining work, and the invariants that protect the recorded results:
  [NEXT_STEPS.md](NEXT_STEPS.md).
- UI changes: read [DESIGN.md](DESIGN.md) for the viewer's visual and evidence rules.
